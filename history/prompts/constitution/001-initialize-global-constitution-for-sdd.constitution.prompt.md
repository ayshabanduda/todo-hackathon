## Prompt

Create AGENTS.md for the entire Todo Evolution Hackathon.

This document is the GLOBAL CONSTITUTION and applies to ALL phases
(Phase I through Phase V). It must not be modified per phase.

PROJECT PHILOSOPHY:
This project follows strict Spec-Driven Development (SDD).
The human acts as a system architect.
AI agents act as implementers.

HUMAN (ARCHITECT) CONSTRAINTS:
- The human must NOT write, edit, or refactor source code manually.
- The human may only create or modify:
  - specifications
  - plans
  - task definitions
  - agent and skill definitions
- All source code must be generated by AI agents through approved tasks.

AGENT PERMISSIONS:
- AI agents are authorized to create, modify, and refactor code.
- Agents may only implement work that is explicitly linked to a Task ID.
- Agents must not generate code without an approved task.

HIERARCHY OF TRUTH (STRICT):
1. Constitution (AGENTS.md)
2. Specifications (sp.spec)
3. Plans (sp.plan)
4. Tasks (sp.task.create)

RULES:
- No Task ID → No Code
- Tasks must be defined before execution
- Agents must follow the latest approved spec and plan
- If specs change, tasks must be regenerated
- Code must include comments referencing Task ID(s)

SCOPE & EVOLUTION:
- The system will evolve across multiple phases
- Technologies, architectures, and storage models may change
- The Constitution remains constant across all phases

AUDITABILITY:
- Every behavior in the system must be traceable to a Task ID
- Every Task ID must trace back to a specification

GOAL:
Shift the role of the human from syntax writer to system architect,
using AI agents to build software through specifications alone.
